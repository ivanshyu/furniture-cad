# D07 雙橫段試款 — 下移與全厚貫穿

本次雙橫條在上一版位置再下移50 mm；上條頂面距拱冠起點76 mm。每條120 × 14 × 20 mm、條間淨空14 mm；每腳兩段、共8段胡桃木，貫穿整個腳厚，正背面與側邊皆可見。

不再是4 mm淺嵌條。每腳楓木被截為三個實際獨立零件，各段與胡桃木段只建名義接觸面，尚未加入榫／銷或其他連接。不得將零碰撞當成可承重；尤其不得依賴未驗證的端面膠合。此試款為L1造型比較，非施工圖；原本基準版不變。

使用 TB001_D07_OUT 環境變數指向本資料夾，執行 FreeCAD 生成器、展示與尺寸圖腳本。本款七視角 AI 已完成，均以此版 CAD 分別生成；不可與無橫段基準版混用。

## 下層 Ø520 比例試版
上桌面Ø650、總高550、下層面高300及雙橫段高度位置不變。下層由Ø450改Ø520，四腳中心半徑由240改275（各徑向外移35 mm），保留5 mm徑向間隙；X桿同步由516加長至586 mm。腳、飾條截面不變。下層面積增加約33.5%；更長X桿的剛度與接合強度仍未驗證。上一個Ø450版本的參數與預覽保存在history/lower_450。
