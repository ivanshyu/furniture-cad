# Maturity Gates

## L0 — Reference

- 已建立 item identity、用途及權利狀態。
- 所有來源有 source ID、檔名/URL、取得日期與簡要評估。

## L1 — Reconstruction

- Overall dimensions 有可追蹤來源。
- 主要輪廓與比例已由至少兩個視角或等效證據交叉檢查。
- 幾何可信度與缺失資料已列出。

## L2 — Engineering

- 零件分解、材料、連接方式、受力路徑與製程已定義。
- 主要安全、人體工學、材料活動及可加工性風險已審查。
- 尚未驗證的假設有明確驗證計畫。

## L3 — Prototype

- 原型用 drawings、BOM、cut list、joinery 與 assembly 齊全且 revision 一致。
- 關鍵公差、量測點及原型驗收標準已定義。
- 文件明確標示 `PROTOTYPE — NOT FOR PRODUCTION`。

## L4 — Production Ready

- 安全、功能、裝配與關鍵外觀問題全部關閉。
- `[ASSUMED]` 已驗證或成為經批准、可追蹤的設計決策。
- 原型回饋已反映至凍結文件；BOM、圖紙、cut list revision 一致。
- QC checklist 已完成並由負責人簽核。
