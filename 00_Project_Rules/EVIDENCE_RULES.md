# Evidence Rules

## 來源優先級

1. 實物校準量測、帶尺寸的正式製造圖
2. 製造商規格、專利文件、可靠館藏紀錄
3. 正交或近正交且可校準的照片
4. 多張一致的商業照片、型錄文字
5. 單張透視照片、二手描述、相似產品慣例

低優先級來源不能直接覆蓋高優先級來源。衝突必須保留並記錄。

## 推導尺寸要求

每個 `[DERIVED]` 值至少記錄：來源 ID、基準尺寸、測量像素或幾何關係、計算式、透視修正、誤差範圍、推導日期。

## 可信度

- High：多個獨立高品質來源一致，或直接量測。
- Medium：推導方法合理且有交叉驗證，但仍有可見誤差。
- Low：單一或模糊來源、重度透視、遮擋，或依慣例推定。

可信度不是證據狀態；例如 `[DERIVED]` 可以是 High 或 Low。
