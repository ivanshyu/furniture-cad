# 房A 主臥室 · BASE01

本地可修改的初步空間模型。以使用者尺寸為基準，加入頂天系統櫃、床佔位、右側窗及冷氣側包管。家具細節待補。

- `models/BASE01/index.html`：互動檢視，含俯視與尺寸提示；3D元件首次載入需網路。
- `models/BASE01/room_a.glb`：可匯入3D軟體的模型（m）。
- `models/BASE01/preview.svg`：平面尺寸預覽。
- `models/BASE01/parameters.json`：可編輯的尺寸基準（mm）。
- `models/BASE01/geometry_mm.json`：具名量體與來源狀態。

重建：在專案根目錄執行 `python3 scripts/room_a_base.py`。

已知尺寸見 `research/evidence_register.md`；推導見 `design/dimensions.md`；暫定值見 `design/open_questions.md`。目前L1，主要尺寸依使用者與圖面，門窗／床細節可信度低；未作施工驗證。原始住宅照片僅保存在本地，未加入公開docs。
