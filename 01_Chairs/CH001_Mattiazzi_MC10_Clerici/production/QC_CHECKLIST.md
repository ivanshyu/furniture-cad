# QC Checklist

## Document control

- [ ] Drawing index、BOM、cut list 與 assembly revision 一致
- [ ] 無未揭露的 `[ASSUMED]` 或 `[TO VERIFY]` 生產關鍵值
- [ ] 材料、五金與 finish 可追溯

## Incoming and machining

- [ ] 材料含水率與缺陷符合規格
- [ ] Datum、關鍵尺寸、配合與對稱度已檢查
- [ ] Joinery dry fit 通過

## Assembly and finish

- [ ] 組裝方正、水平、無 rocking 或異常間隙
- [ ] 膠線、夾痕與表面缺陷符合標準
- [ ] Finish 試片已批准，固化條件已達成

## Release

- [ ] 原型測試及風險項目已關閉
- [ ] Open questions gate 通過
- [ ] Production release 已簽核
