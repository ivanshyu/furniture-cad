## 本稿明確解讀
X 是俯視的交叉，三組位於三個水平面，不是立面的斜撑。腳先安排在內縮正方形的四角，兩方向細桿各沿對角線連接相對腳。腳外輪廓拱頂，窄槽仍是直角矩形；長槽下端由胡桃木腳墊收口。
